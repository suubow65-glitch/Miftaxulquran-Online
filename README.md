# Miftaxul Quran Online - LMS & ERP System

Welcome to the **Miftaxul Quran Online** project! This repository contains the complete source code for our advanced Learning Management System (LMS) and Enterprise Resource Planning (ERP) platform, designed specifically for an online Quran academy.

## Features

- **Comprehensive LMS & ERP**: Integrated system to manage students, courses, exams, and payments.
- **Teacher Portal**: A dedicated portal for teachers to log in, view their assigned students, manage attendance, and submit lesson logs.
- **Parent/Student Tracking**: Easily track progress, exam results, and payment statuses.
- **Quran Player**: Built-in interactive audio player for Quran recitation, listening, and learning.
- **Bilingual Interface**: Seamlessly toggles between English and Soomaali for maximum accessibility.
- **Dynamic CMS**: Update the website's content directly from the admin dashboard (Hero section, Testimonials, Libraries, etc.).

## Technology Stack

- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS
- **State Management**: Zustand (with local persistence)
- **Icons**: Lucide React

## Getting Started

1. Clone the repository.
2. Install dependencies with `npm install`.
3. Run the development server with `npm run dev`.
4. Open [http://localhost:3000](http://localhost:3000) to view the application.
